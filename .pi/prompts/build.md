# Build

Before implementation:
1. Understand the request and relevant project context.
2. For non-trivial work create a short scope contract in `.pi/work/scope.md`.
3. Read the smallest relevant code surface and canonical examples.
4. Make the smallest complete change.
5. Use the verification skill before completion.

Do not expand scope silently. If the implementation grows far beyond the expected area, reconsider the design before continuing.
