# Build

Before implementation:
1. Understand the request and relevant project context.
2. For non-trivial work create a short scope contract in `.pi/work/scope.md`.
3. Read the smallest relevant code surface and canonical examples.
4. Detect material task signals from `.pi/laws/signals.md`.
5. Activate only relevant core laws and specialized skills.
6. For material decisions, record proof obligations in `.pi/work/obligations.md` when useful.
7. Make the smallest complete change.
8. Use verification to collect evidence matching the obligations.

Do not expand scope silently. If implementation grows far beyond the expected area,
reconsider the design before continuing.
