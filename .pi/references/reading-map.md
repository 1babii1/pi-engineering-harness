# Architecture Reading Map

Short references to consult when a design problem appears.

## Microservices Patterns — Chris Richardson
Use for service decomposition, Saga, Transactional Outbox, Database per Service, API Gateway/BFF, service templates, and distributed workflow patterns.

## Designing Data-Intensive Applications — Martin Kleppmann / Chris Riccomini (2nd ed.)
Use for replication, partitioning, transactions, consistency, streams, batch systems, distributed data, and trade-off thinking.

## Google SRE
Use for SLI/SLO, error budgets, monitoring, production reliability, incident response, and the four golden signals.

## Microsoft Azure Architecture Center / AWS Prescriptive Guidance
Use for practical resilience, integration, cloud and distributed patterns. Treat examples as trade-off guidance, not mandatory vendor architecture.

## OWASP + OAuth/OIDC standards
Use for authentication, authorization, session/token security, abuse prevention, and web application threats.

## Kubernetes + OpenTelemetry official docs
Use as the primary source for orchestration and telemetry behavior rather than relying on remembered syntax or old blog posts.
